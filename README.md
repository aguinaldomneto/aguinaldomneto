# 🏗️ Como penso infraestrutura

Meu fluxo de trabalho é baseado em:

```text
        DETECTAR
           │
           ▼
       INVESTIGAR
           │
           ▼
       DIAGNOSTICAR
           │
           ▼
         CORRIGIR
           │
           ▼
       MONITORAR
           │
           ▼
        PREVENIR
```

Infraestrutura não termina quando o serviço volta a funcionar.

O objetivo é entender **por que o problema aconteceu**, restaurar o serviço e criar mecanismos para reduzir a possibilidade de recorrência.
